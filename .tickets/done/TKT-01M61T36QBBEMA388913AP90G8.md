## Description

The no-LLM fast path from docs/BRIDGE-PROTOCOL.md section 9. It works without an API key,
so M1 stays useful even if terva isn't configured.

## Acceptance criteria

- [x] A message counts as addressed when it's a whisper, names the bot, or replies within 20 s
- [x] `follow`, `stop`, `status`, `come here` and `wait here` map to tasks
- [x] Only owners can issue tasks; anyone else gets a polite refusal
- [x] `status` answers from the latest state, and a failed task is explained in chat

## Implementation plan

internal/chat.Brain is the session's Listener. A line counts as addressed when it is a whisper, when it contains agentName as a word, or when it comes within 20 s of the bot speaking to that player. Addressed text is normalised (lower case, punctuation dropped, the bot's name and "please" removed) and matched exactly against the grammar: follow (me), stop/halt, status/report, come (here)/come to me, wait (here)/stay (here). Owners come from the controller's config by name. A non-owner giving a command gets a polite refusal naming the owners. Commands go through session.Dispatch with a chat origin, and TaskDone turns a failed or rejected task with that origin into a sentence to the player who asked. status is built from the newest state. Unmatched addressed lines go to a Voice interface with a short summary and the last 20 lines; with no Voice configured, and on any Voice error, the bot says "Hm?". Replies whisper back to a whisper and speak normally otherwise.
