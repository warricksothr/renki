## Description

Implement an explicit selected-layer exchange boundary for the durable atlas, following docs/ATLAS.md. Begin with terrain/biome snapshots and a versioned manifest covering world namespace/epoch, local Cartesian coordinates, resolution, schema, hashes, measurement times and provenance. Validate GeoPackage/local-coordinate support with established tools; numeric coverage must preserve heights/nodata. Initial import previews may remain read-only until compatibility/conflict policy is established. COG/PMTiles are later options, not mandatory dependencies. This ticket does not publish or upload data.

## Acceptance criteria

- [ ] Export/import contract preserves local (x,z) metres, +y elevation, negative coordinates, nodata, original ages and world/epoch identity
- [ ] Selected terrain/biome snapshots exclude player histories, chest contents, private waypoints and server connection details by default
- [ ] Import preview validates bounds/size/schema/hash/compatibility, preserves provenance and conflicts, and never treats ingestion time as fresh local observation
- [ ] Round-trip and suitable external validation prove retained numeric values and coordinate metadata; no Earth CRS is falsely assigned
